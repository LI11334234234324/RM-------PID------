# 底盘闭环控制器调参实验记录与工程复盘

> **调参原则**：
> 真实电控开发严禁"盲目碰运气"，每一组参数的调整都必须有明确的物理现象观察、理论机理支撑和预期改进目标。
> 串级控制遵循 **"先内环后外环、先比例后积分、慎用微分"** 的标准流程。

---

## 1. 实验 1：速度内环纯 P 增益调节与稳态误差分析

### 1.1 实验步骤与波形观察
1. 将积分增益 $K_i = 0$、微分增益 $K_d = 0$；
2. 施加 $20.0\text{ rad/s}$ 的阶跃目标转速，系统带有 $15\%$ 动摩擦阻力；
3. 逐步将 $K_p$ 从 $0.5$ 提升到 $1.8$，再提升到 $4.5$。

```
实验波形记录 (纯 P 响应):
目标值 (20.0) ─────────────────────────────────────────────
Kp = 4.5       ──────/\/\/\/\/\/\/\/\/\────── (高频剧烈振荡，静差 ~ 1.2 rad/s)
Kp = 1.8       ────────────────────────────── (稳定无振荡，但静差高达 4.5 rad/s)
Kp = 0.5       ------------------------------ (响应极其迟缓，稳态值仅 10.0 rad/s)
```

### 1.2 机理分析与结论
- 当 $K_p = 0.5$ 时，比例恢复力不足以克服摩擦阻力，响应迟钝且静差高达 $50\%$；
- 当 $K_p = 1.8$ 时，系统响应加快，响应平稳，但依然存在不可消除的稳态静差（实测 $15.5\text{ rad/s}$）；
- 当 $K_p \ge 4.5$ 时，系统相位裕度急剧缩小，出现持续的高频发散振荡，且依然无法彻底消除静差。
- **阶段结论**：纯 P 控制器无法同时满足"快速响应"与"零静差"要求，确定最佳内环 $K_p = 2.0 \sim 2.2$，必须引入积分环节 $I$。

---

## 2. 实验 2：引入积分项 $I$ 与积分饱和现象复现

### 2.1 实验步骤
1. 固定 $K_p = 2.2$，$K_d = 0$；
2. 引入较强的积分增益 $K_i = 25.0$，**暂时关闭抗积分饱和机制 (`anti_windup = False`)**；
3. 施加 $20.0\text{ rad/s}$ 阶跃。

### 2.2 现象与波形记录
- **现象**：速度稳态误差彻底降为 0（精准稳定在 $20.000\text{ rad/s}$）；
- **严重缺陷**：在响应上升阶段，电机达到最大输出限幅（$+30.0$），在此期间积分项持续疯狂累加至 $I_{\text{out}} \approx 85.0$。当实际转速达到 $20.0\text{ rad/s}$ 时，巨大的积分余量无法快速释放，导致系统冲高至 $27.5\text{ rad/s}$，**产生高达 $37.5\%$ 的超调量**，并经历长达 $0.4\text{ 秒}$ 的回落振荡。

---

## 3. 实验 3：启用 Anti-Windup 动态反算抗饱和

### 3.1 实验步骤
1. 保持 $K_p = 2.2$，$K_i = 25.0$；
2. **启用抗积分饱和 (`anti_windup = True`)**，开启饱和条件反算冻结与 $I_{\text{max}} = 20.0$ 独立幅值钳位。

### 3.2 现象与对比
- **波形表现**：上升时间仅需 $0.08\text{ 秒}$，系统**超调量由 $37.5\%$ 彻底归零（$0\%$ 超调）**，平滑无冲地贴合目标转速，且稳态误差精确为 0。
- **对比图谱**：详见 `output/pid_step_response.png` 与 `output/pid_step_response.gif` 中的绿线（PI With Anti-Windup）与橙线（PI No Anti-Windup）。

## 4. 实验 4：外环航向 P 增益与抗扰度整定

在完成内环 4 轮速度闭环后，进入外环航向角控制整定：
1. 底盘注入不对称扰动：左侧轮摩擦衰减 $15\%$，同时施加 $0.12\text{ N}\cdot\text{m}$ 的偏心自转力矩；
2. 保持速度内环参数不变，调节外环 $K_{p, \text{heading}}$：
   - $K_{p, \text{heading}} = 1.0$：纠偏能力弱，底盘在轨迹转弯处发生明显跑偏（航向滞后 $> 15^\circ$）；
   - $K_{p, \text{heading}} = 4.5$：纠偏迅速果断，航向动态跟踪误差 $< 2^\circ$，正方形与 8 字轨迹紧密贴合；
   - $K_{p, \text{heading}} = 10.0$：外环输出角速度指令过于剧烈，底盘在直线段出现明显的"蛇形摆头（Fishtailing）"。
3. **最终收敛值**：选取 $K_{p, \text{heading}} = 4.5$。

## 6. RM 电控调参黄金口诀与实车避坑总结

```
【电控调参口诀】
先调内环后外环，先调比例后积分；
比例给到微振荡，回退三成最稳当；
积分引入消静差，抗饱和限制不能少；
微分抑制加阻尼，噪声滤波要跟上；
外环比例定刚度，太快摆头太慢漂。
```

### 实车避坑要点：
1. **机械共振频率避让**：M3508 刚性安装在铝合金底盘上时，若 $K_p$ 过高会在 $100\sim 300\text{ Hz}$ 触发底盘机械共振，整车发出刺耳金属嗡鸣声。此时必须果断下调 $K_p$ 并加入低通滤波。
2. **积分分离与输出软起动**：在遥控器急推摇杆时，可设置误差门限：当 $|e| > e_{\text{threshold}}$ 时关闭积分，进入小误差区间后再开启积分，能进一步消除冲击。
