### Q1: 麦轮为什么能实现全向移动？受力与速度合成原理是什么？
- **核心答案要点**：
  - **结构特征**：麦轮轮毂外圈均匀分布着与主轴成 $\pm 45^\circ$ 夹角的自由旋转小辊子（Roller）。
  - **受力分解**：电机驱动主轴旋转时，地面静摩擦力沿与辊子垂直的 $45^\circ$ 方向作用在轮子上。该力分解为沿车身纵向的前后牵引力 $F_x$ 与沿车身横向的侧向力 $F_y$。
  - **矢量叠加**：4 个车轮产生的纵向和横向分力在底盘质心处进行矢量叠加。通过控制 4 个电机的转速正负与比例，可以使非期望方向的分力相互抵消，期望方向的分力相互加强，从而在不依赖转向舵机的前提下实现任意平移与原地旋转。

### Q2: 为什么 RM 实车全面采用 O 型麦轮布局，而不是 X 型布局？
- **核心答案要点**：
  - 俯视底盘时，4 轮与地面接触的辊子母线延伸方向呈"外八字（O 型）"或"内八字（X 型）"。
  - **自转力矩臂差异**：O 型布局中，各轮侧向分力对底盘中心的力矩臂长等于前后半轴距与左右半轮距之和 $(L_x + L_y)$，能产生巨大的自转力矩，自转响应敏捷稳定；而 X 型布局的力矩臂为 $|L_x - L_y|$，当底盘为正方形时力矩臂甚至退化为 0（无法原地旋转）。
  - **抗打滑能力**：O 型布局受到外界横向碰撞或单轮打滑时，地面支持力与摩擦力矩具备较好的自稳定性，不易发生侧翻与姿态奇异。因此 RM 全面采用 O 型布局。

<a id="q3"></a>
### Q3: 麦轮底盘正逆运动学公式如何推导？矩阵维度与物理含义是什么？
- **核心答案要点**：
  - **逆运动学 (IK, 4x3 矩阵)**：从底盘期望速度 $\mathbf{V}_b = [v_x, v_y, \omega]^T$ 解算 4 轮目标线速度：
    $$\begin{bmatrix} v_{\text{fl}} \\ v_{\text{fr}} \\ v_{\text{rl}} \\ v_{\text{rr}} \end{bmatrix} = \begin{bmatrix} 1 & -1 & -(L_x + L_y) \\ 1 & 1 & (L_x + L_y) \\ 1 & 1 & -(L_x + L_y) \\ 1 & -1 & (L_x + L_y) \end{bmatrix} \begin{bmatrix} v_x \\ v_y \\ \omega \end{bmatrix}$$
    角速度 $\omega_i = v_i / R$。
  - **正运动学 (FK, 3x4 矩阵)**：基于摩尔-彭罗斯伪逆矩阵 $\mathbf{H}_{\text{fk}} = (\mathbf{H}^T\mathbf{H})^{-1}\mathbf{H}^T$：
    $$\begin{aligned}
    v_x &= \frac{R}{4}(v_{\text{fl}} + v_{\text{fr}} + v_{\text{rl}} + v_{\text{rr}}) \\
    v_y &= \frac{R}{4}(-v_{\text{fl}} + v_{\text{fr}} + v_{\text{rl}} - v_{\text{rr}}) \\
    \omega &= \frac{R}{4(L_x + L_y)}(-v_{\text{fl}} + v_{\text{fr}} - v_{\text{rl}} + v_{\text{rr}})
    \end{aligned}$$

### Q4: 底盘在高速平移叠加小陀螺时发生轮速饱和怎么办？
- **核心答案要点**：
  - **单轮截断的缺陷**：若某轮计算速度超过电机上限（如 $30\text{ rad/s}$），若直接对其单轮截断，破坏了四轮分力配比，会导致底盘严重跑偏和自转失速。
  - **等比例衰减 (Desaturation / Scaling)**：
    1. 统计四轮目标速度的最大绝对值 $\omega_{\text{req, max}} = \max(|\omega_{\text{fl}}|, |\omega_{\text{fr}}|, |\omega_{\text{rl}}|, |\omega_{\text{rr}}|)$；
    2. 若 $\omega_{\text{req, max}} > \omega_{\text{limit}}$，则计算缩放系数 $k = \frac{\omega_{\text{limit}}}{\omega_{\text{req, max}}}$；
    3. 将 4 轮转速统一乘以 $k$。
  - **效果**：牺牲部分线速度大小，但严格保全了运动方向角与角速度比例。

<a id="q5"></a>
### Q5: 简述 P、I、D 各项物理意义，速度环为什么通常只用 PI 而慎用 D？
- **核心答案要点**：
  - **P (比例)**：与当前误差成正比，提供基础驱动力，决定响应快慢。
  - **I (积分)**：对历史误差积分，提供持续纠偏力，**核心作用是消除稳态静差**。
  - **D (微分)**：对误差变化率求导，提供超前阻尼，抑制超调与震荡。
  - **为什么速度环慎用 D**：
    1. 电机磁编码器反馈的速度信号是通过离散差分（如 $M$ 法）计算的，天然伴随量化阶梯噪声；
    2. 微分运算等效于高通滤波器，会将高频量化噪声放大数十倍，导致输出控制量剧烈抖动，表现为电机高频啸叫、发热严重甚至驱动 MOS 管烧毁；
    3. 电机本身是一阶惯性系统，速度闭环用 PI 控制器即可实现无超调、无静差的极佳响应。

<a id="q6"></a>
### Q6: 什么是积分饱和 (Integral Windup)？如何实现 Anti-Windup？
- **核心答案要点**：
  - **机理**：当大阶跃输入或外载严重受限时，控制器输出达到最大物理限幅 $u_{\text{max}}$，误差持续存在，积分项无休止膨胀（Windup）。当反馈接近目标时，因积分量巨大无法及时退饱和，导致输出长时间维持极大值，引发**严重超调和剧烈回落振荡**。
  - **防护手段（条件反算抗饱和）**：
    1. 预计算输出；
    2. 当输出饱和且误差方向与饱和方向同向时（继续推大饱和），立即**冻结积分累加**；
    3. 对积分累计值设置独立的上下限限幅 (`np.clip(integral, -max_i, max_i)`)。

<a id="q7"></a>
### Q7: 纯 P 控制为什么在有阻力时必定存在稳态静差？数学上如何证明？
- **核心证明**：
  - 一阶受控对象带有摩擦阻尼 $B$：$\omega_{ss} = K u_{ss} - B \omega_{ss} \implies \omega_{ss} = \frac{K u_{ss}}{1 + B}$。
  - 纯 P 控制律：$u_{ss} = K_p (r - \omega_{ss})$。
  - 联立解得稳态误差：
    $$e_{ss} = r - \omega_{ss} = \frac{1 + B}{1 + B + K K_p} \cdot r > 0$$
  - **结论**：因为 $K_p$ 物理上不可能为无穷大（过大会引发高频发散），所以只要阻尼 $B > 0$，纯 P 控制的静差永远存在，必须引入积分环节 $I$。

### Q8: 请简述 Ziegler-Nichols 整定法与实车调参的黄金流程。
- **核心答案要点**：
  - **Z-N 阶跃法原理**：测量对象在开环阶跃下的响应曲线，提取等效时间常数 $\tau$、纯滞后 $L$ 与增益 $K$，利用经验公式（如 PI: $K_p=0.9\frac{\tau}{KL}, T_i=3.33L$）给出初始值。
  - **实车调参黄金流程**：
    1. **先内环后外环**：先调 4 个电机的速度 PI 环，再调底盘航向/位置外环；
    2. **先 P 后 I**：先将 $K_i=0, K_d=0$，逐渐加大 $K_p$ 直至出现轻微临界振荡，然后回退约 $30\%$；
    3. **引入 I 项**：从小到大增加 $K_i$，直至稳态误差在预期时间内收敛到 0；
    4. **开启 Anti-Windup**：设定合理的积分限幅，消除阶跃超调。

<a id="q9"></a>
### Q9: 底盘双环串级控制（航向外环 + 速度内环）的数据流向与调参顺序？
- **核心答案要点**：
  - **控制数据流**：
    $$\text{目标航向 } \theta_{\text{target}} \xrightarrow{\text{航向 P 外环}} \text{期望自转角速度 } \omega_{\text{target}} \xrightarrow{+ (v_x, v_y) \text{ 逆运动学 IK}} \text{四轮目标转速 } \omega_i \xrightarrow{\text{四轮速度 PI 内环}} \text{电机电流指令 } u_i$$
  - **调参顺序**：
    - **必须先调内环**：内环速度环响应频率要求高（通常 $100\sim 200\text{ Hz}$），只有内环能够快速、准确、无超调地跟踪速度指令，外环才能将内环等效为响应良好的理想执行机构；
    - **再调外环**：外环为航向角 P 控制（带宽通常为内环的 $1/5 \sim 1/10$），调节 $K_p$ 获得平稳纠偏刚度，避免蛇形摆头。

<a id="q10"></a>
### Q10: 增量式编码器测速原理是什么？M法、T法、M-T法有何区别？
- **核心答案要点**：
  - **M 法 (测频率法)**：在固定的时间间隔 $T_c$ 内统计编码器脉冲数 $M_1$，计算公式 $n = \frac{M_1}{Z \cdot T_c}$。**适合高速测量**（低速时脉冲少，量化误差大）。
  - **T 法 (测周期法)**：测量两个相邻编码器脉冲之间的高频基准时钟脉冲数 $M_2$。**适合低速测量**（高速时基准时钟脉冲过少，相对误差大）。
  - **M-T 法 (混合法)**：在固定的时间门宽 $T_g$ 内，等待编码器下一个脉冲到来的同时统计编码器脉冲数与高频时钟数。**全速段高精度**，大疆 C620 电调内部即采用类似测速算法。

### Q11: STM32 与大疆 C620 电调之间是如何通过 CAN 总线通信的？
- **核心答案要点**：
  - **物理层**：CAN 差分信号 (CAN_H, CAN_L)，终端接 $120\Omega$ 匹配电阻，波特率通常配置为 **$1\text{ Mbps}$**。
  - **控制指令发送 (STM32 -> 电调)**：
    - 标识符 `0x200`（控制 ID 1~4 号电机）：8 字节负载，每 2 字节（int16）代表一个电机的目标转矩电流指令值（$-16384 \sim +16384$，对应 $-20\text{A} \sim +20\text{A}$）。
  - **反馈数据接收 (电调 -> STM32)**：
    - 标识符 `0x201 ~ 0x204`：电调以 $1\text{ kHz}$ 频率主动上报。8 字节数据分别包含：转子机械角度（0~8191，uint16）、转速（RPM，int16）、实际转矩电流（int16）、电机温度（uint8）。

<a id="q12"></a>
### Q12: STM32 定时器 (TIM) 在电控系统中有哪些核心用途？
- **核心答案要点**：
  1. **定时中断 (Base Timer)**：作为系统核心控制节拍（如 $1\text{ ms}$ 定时中断），周期性触发 PID 运算与状态机调度；
  2. **PWM 输出 (PWM Generation)**：驱动舵机、摩擦轮电机或控制加热电阻（利用 TIM 的比较输出通道 OC）；
  3. **编码器接口模式 (Encoder Interface)**：硬件自动对编码器 A/B 正交相进行 4 倍频计数并判断正反转，完全不占用 CPU 运算资源；
  4. **输入捕获 (Input Capture)**：测量遥控器接收机 DBUS/PPM 脉冲宽度或超声波回波时间。

<a id="q13"></a>
### Q13: 什么是陀螺仪零偏？为什么纯轮速计里程计积分会发散？
- **核心答案要点**：
  - **陀螺仪零偏 (Gyroscope Bias)**：MEMS 陀螺仪在静止状态下输出的非零常值角速度偏移。即使静止，积分也会导致航向角线性漂移。
  - **轮速计里程计发散原因**：
    1. 麦轮辊子在与地面接触时存在微观滑动与打滑；
    2. 地面平整度与轮子磨损不对称导致正运动学解算速度存在持续误差；
    3. 航向角误差会随着时间累积，导致 $(v_x, v_y)$ 在世界坐标系的旋转投影严重畸变。
  - **实车对策**：在实车上采用 IMU（BMI088）通过卡尔曼滤波（EKF）融合陀螺仪与加速度计，获取高精度无漂移航向，外环用陀螺仪航向闭环。

<a id="q14"></a>
### Q14: RoboMaster 裁判系统底盘功率限制 (60W~120W) 电控如何实现？
- **核心答案要点**：
  - **裁判系统机制**：裁判系统主控实时检测底盘供电母线电压 $U$ 与电流 $I$，计算实时功率 $P = U \cdot I$。超出功率上限后会消耗底盘缓冲能量（60J），缓冲能量耗尽将直接扣血。
  - **经典电控限功率算法**：
    1. **功率预测模型**：单电机电功率 $P_i = k_1 \cdot \tau_i \cdot \omega_i + k_2 \cdot \tau_i^2 + P_{\text{loss}}$（机械功 + 铜损 + 铁损）；
    2. **总功率预估**：$P_{\text{total}} = \sum_{i=1}^4 P_i$；
    3. **等比例缩放限制**：当 $P_{\text{total}} > P_{\text{limit}}$ 时，计算缩减系数 $k = \sqrt{\frac{P_{\text{limit}}}{P_{\text{total}}}}$ 或按剩余缓冲能量动态调整 PID 输出上限 $u_{\text{max}}$，对 4 轮输出电流等比压缩。

### Q15: 【核心实操】本项目 Python 代码如何一步步移植到 STM32 C 工程？

以下为本项目各 Python 核心算法向 STM32 C 语言工程的一对一移植规范与生产级 C 源码：

#### 1. PID 控制器 C 语言实现 (`pid.h` / `pid.c`)

```c
// ================= pid.h =================
#ifndef PID_H
#define PID_H

typedef struct {
    float kp, ki, kd;
    float max_output;
    float max_integral;
    float dt;
    
    float target;
    float feedback;
    float error;
    float prev_error;
    float integral;
    float p_out, i_out, d_out;
    float output;
} PID_t;

void PID_Init(PID_t *pid, float kp, float ki, float kd, float max_out, float max_i, float dt);
float PID_Calc(PID_t *pid, float target, float feedback);
void PID_Reset(PID_t *pid);

#endif
```

```c
// ================= pid.c =================
#include "pid.h"
#include <math.h>

void PID_Init(PID_t *pid, float kp, float ki, float kd, float max_out, float max_i, float dt) {
    pid->kp = kp;
    pid->ki = ki;
    pid->kd = kd;
    pid->max_output = max_out;
    pid->max_integral = max_i;
    pid->dt = dt;
    PID_Reset(pid);
}

void PID_Reset(PID_t *pid) {
    pid->integral = 0.0f;
    pid->prev_error = 0.0f;
    pid->output = 0.0f;
}

float PID_Calc(PID_t *pid, float target, float feedback) {
    pid->target = target;
    pid->feedback = feedback;
    pid->error = target - feedback;

    // 1. 比例项
    pid->p_out = pid->kp * pid->error;

    // 2. 微分项
    pid->d_out = pid->kd * (pid->error - pid->prev_error) / pid->dt;
    pid->prev_error = pid->error;

    // 3. 抗积分饱和条件反算
    float temp_out = pid->p_out + (pid->integral * pid->ki) + pid->d_out;
    int can_integrate = 1;
    if (temp_out >= pid->max_output && pid->error > 0.0f) {
        can_integrate = 0;
    } else if (temp_out <= -pid->max_output && pid->error < 0.0f) {
        can_integrate = 0;
    }

    if (can_integrate && pid->ki != 0.0f) {
        pid->integral += pid->error * pid->dt;
        // 积分限幅
        float i_limit = pid->max_integral / pid->ki;
        if (pid->integral > i_limit) pid->integral = i_limit;
        if (pid->integral < -i_limit) pid->integral = -i_limit;
    }
    pid->i_out = pid->ki * pid->integral;

    // 4. 总输出限幅
    float raw_out = pid->p_out + pid->i_out + pid->d_out;
    if (raw_out > pid->max_output) pid->output = pid->max_output;
    else if (raw_out < -pid->max_output) pid->output = -pid->max_output;
    else pid->output = raw_out;

    return pid->output;
}
```

#### 2. 麦轮逆运动学解算与等比限幅 C 语言实现 (`chassis_kinematics.c`)

```c
#include "pid.h"
#include <math.h>

#define WHEEL_RADIUS      0.076f  // 轮半径 76mm
#define CHASSIS_L_SUM     0.400f  // Lx + Ly = 200mm + 200mm = 400mm
#define MAX_WHEEL_SPEED   30.0f   // 单轮最大角速度 rad/s

void Chassis_Inverse_Kinematics(float vx, float vy, float omega, float *wheel_target_rad_s) {
    // 1. 逆运动学计算
    wheel_target_rad_s[0] = (vx - vy - CHASSIS_L_SUM * omega) / WHEEL_RADIUS; // FL
    wheel_target_rad_s[1] = (vx + vy + CHASSIS_L_SUM * omega) / WHEEL_RADIUS; // FR
    wheel_target_rad_s[2] = (vx + vy - CHASSIS_L_SUM * omega) / WHEEL_RADIUS; // RL
    wheel_target_rad_s[3] = (vx - vy + CHASSIS_L_SUM * omega) / WHEEL_RADIUS; // RR

    // 2. 轮速饱和等比例衰减 (Desaturation)
    float max_val = 0.0f;
    for (int i = 0; i < 4; i++) {
        float abs_val = fabsf(wheel_target_rad_s[i]);
        if (abs_val > max_val) max_val = abs_val;
    }

    if (max_val > MAX_WHEEL_SPEED) {
        float scale = MAX_WHEEL_SPEED / max_val;
        for (int i = 0; i < 4; i++) {
            wheel_target_rad_s[i] *= scale;
        }
    }
}
```
